Design rules

  • Tokens use shadcn names (--background, --primary, --muted…) as HSL triplets, so hsl(var(--primary)) works with Tailwind.
  • Light and dark: prefers-color-scheme plus a manual data-theme override.
  • Every async view shows loading, empty and error states.
  • Role-hidden controls use .can-edit here; in React use <Can action="…">. The server still enforces permissions.
  • Under 800px the sidebar becomes a drawer and board columns snap-scroll (~84vw wide) down to 360px.
